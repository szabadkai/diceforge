# Formlabs dice marks

The five sample-part marks come from the inline SVG illustrations on Formlabs' current Form 4 product page:

- `game-controller.svg` — Game Controller
- `led-light-bar.svg` — LED Light Bar and Mount
- `robotic-finger.svg` — Robotic Finger
- `tower-cap.svg` — Tower Cap
- `connector.svg` — Electrical Connector

Source: <https://formlabs.com/global/3d-printers/form-4/>

The source strokes were widened, given rounded joins, and expanded to filled vector outlines so DiceForge's SVG-to-solid pipeline can subtract them as manifold engraving geometry. The artwork was not redrawn into substitute icons.

Formlabs' public press media kit was also checked, but its current ZIP contains raster product photographs rather than an engraving-ready vector set: <https://formlabs.com/company/press/>
